Лекция 1: Въведение в MVC и настройка на проекта
Цели на обучението
Разбиране на архитектурата MVC и нейните компоненти: Model, View, Controller.
Настройка на средата за разработка.
Създаване на нов ASP.NET MVC проект.
Съдържание
Какво е HTTP?
Защо ни е нужен HTTP? Клиент–сървър модел.
Структура на HTTP заявка (метод, URL, хедъри, тяло).
HTTP методи: GET, POST, PUT, DELETE.
Структура на HTTP отговор.
Често срещани статус кодове: 200, 301, 302, 400, 401, 403, 404, 500.
Какво е .NET, ASP.NET, C#
Какво е framework и защо ни улеснява.
.NET SDK, runtime, CLI (dotnet new, dotnet run).
Основи на C# (преговор, ускорено темпо)
Защо C# за уеб разработка.
Структура на C# програма; типове данни и променливи.
Управляващи конструкции (if, switch, цикли).
Колекции: масиви, List<T>, Dictionary<K,V>.
Методи и параметри; класове и обекти; свойства.
Работа с изключения (try / catch / finally).
LINQ – само базовите оператори Where, Select, OrderBy, FirstOrDefault.
Какво е MVC?
Преглед на Model, View и Controller и ролята на всеки компонент.
Разделяне на отговорностите; предимства на архитектурата.
Жизнен цикъл на една заявка в ASP.NET Core MVC.
Инсталиране и настройка на инструментите
Изтегляне на .NET SDK.
Visual Studio Community Edition или алтернатива според ОС.
Настройка на SQL Server Express / LocalDB и SQL Server Management Studio.
Създаване на първия ASP.NET MVC проект
Стъпка по стъпка създаване на проект (шаблон ASP.NET Core Web App (MVC)).
Структура на папките: Models, Views, Controllers, wwwroot.
Роля на Program.cs и appsettings.json.
Практически пример: стартиране на уебсайта за библиотеката

Стартиране и разглеждане на генерираната страница в браузъра.

Лекция 2: Контролери и маршрутизиране
Цели на обучението
Как работят контролерите в MVC.
Как маршрутизирането свързва URL адреси с контролери и действия.
Съдържание
Какво е контролер?
Роля на контролерите при обработката на HTTP заявки.
Създаване на персонализиран контролер в папка Controllers.
Конвенции за именуване (XxxController).
Добавяне на действия (actions)
Дефиниране на действия и връщане на изглед (IActionResult, View()).
Приемане на параметри от URL и от заявка.
Пример: LibraryController с действие Index.
Маршрутизиране (Routing)
Как маршрутът свързва URL с метод за действие.
Конвенционално маршрутизиране ({controller}/{action}/{id?}).
Атрибутно маршрутизиране ([Route], [HttpGet]).
Практически пример: основни страници
LibraryController с действия за начална страница (Index), „За нас“ (About) и „Контакт“ (Contact).
Практическа задача
Създайте LibraryController и дефинирайте основните методи за действие.
Добавете персонализирани маршрути, така че страниците да се отварят на конкретни URL адреси.

Цели на обучението
Създаване и персонализиране на изгледи в MVC.
Използване на Bootstrap за основно стилизиране.
Съдържание
Какво е изглед?
Роля на изгледите при представянето на данните.
.cshtml файлове: C# + HTML + CSS.
Роля на HTML и CSS; основни HTML елементи и структура на документа; CSS основи (селектори, кутиен модел).
Razor синтаксис за динамично рендиране (@, @if, @foreach, @model).
Глобални изгледи (_Layout), частични изгледи (partial views) и секции (sections).
Създаване и персонализиране на изгледи
Изглед за метод на действие в контролера.
Предаване на данни от контролера към изгледа: ViewData, ViewBag и ViewModel (препоръчителен подход).
Стилизиране с Bootstrap
Включване на Bootstrap в проекта.
Grid система, компоненти (navbar, card, table, form), отзивчив дизайн.
Практически пример: начална страница
Изглед за действието Index в LibraryController.

Практическа задача

Лекция 4: Интегриране на база данни с Entity Framework Core
Цели на обучението
Роля на модела в MVC.
Използване на Entity Framework за свързване с база данни.
Съдържание
Какво е модел?
Роля на моделите за представяне на данните.
Въведение в ORM и Entity Framework Core.
Настройка на базата данни
Създаване на SQL Server база данни за библиотеката.
Connection string в appsettings.json.
Модел Book с полета Title, Author, PublishedDate, ISBN.
Code-First подход
DbContext и DbSet<T>; регистрация чрез Dependency Injection.
Атрибути за данни: [Key], [Required], [MaxLength], [DataType].
Миграции: Add-Migration / Update-Database (Package Manager Console) или dotnet ef migrations add / dotnet ef database update.
Начално зареждане на данни (seeding).
Практически пример: списък с книги
BookController, инжектиране на DbContext.
Извличане на списък с книги и показването му в изглед (таблица с Bootstrap).
Практическа задача
Създайте модел Book, генерирайте базата данни чрез миграция.
Покажете списък с книги на уебсайта на библиотеката.
 
Лекция 5: CRUD операции и завършване на уебсайта
Цели на обучението
Реализиране на CRUD операции за управление на данни.
Отстраняване на грешки и подготовка за разгръщане.
Съдържание
Какво са CRUD операции?
Създаване, четене, редактиране и изтриване на записи.
Реализация в контролер: GET/POST двойки действия.
Форми за въвеждане на данни
Razor форми и Tag Helpers: asp-for, asp-action, asp-validation-for.
Валидация от страна на модела (Data Annotations) и в изгледа (ModelState.IsValid, validation summary).
Защита срещу CSRF: [ValidateAntiForgeryToken].
CRUD в BookController
Добавяне на нова книга; преглед на детайли; редактиране; изтриване с потвърждение.
Използване на scaffolding за автоматично генериране и последващо ръчно доработване.
Откриване и отстраняване на грешки
Debugger във Visual Studio: breakpoints, watch, call stack.
Developer Exception Page, страници за грешки, логване.
Разгръщане (deployment)
Публикуване към IIS / Azure App Service; publish профил.
Прилагане на миграции към продукционна база.
Практически пример: завършване на уебсайта за библиотеката
Пълна функционалност за управление на каталога и тестване на приложението.
Практическа задача
Реализирайте CRUD операции за модела Book.
Тествайте приложението — добавяне, редактиране и изтриване на книги.
