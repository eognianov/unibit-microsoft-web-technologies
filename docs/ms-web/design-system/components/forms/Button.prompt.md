A Fluent-style call-to-action button with primary/secondary/subtle/danger variants and three sizes.

```jsx
<Button variant="primary" size="medium">Save changes</Button>
<Button variant="secondary" icon="/assets/icons/chevron_down_20_regular.svg">More</Button>
```

Variants: `primary` (solid brand blue), `secondary` (outlined), `subtle` (text-only), `danger` (solid red). Sizes: `small` `medium` `large`. Pass `disabled` to dim and block clicks.
